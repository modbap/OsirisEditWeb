Lineage

This editor descends from prior open-source work in three stages:

  • WaveEdit
    © 2017 Andrew Belt, developed for Synthesis Technology · GPL-3.0

    The original C++ / OpenGL wavetable editor, and the source of the DSP engine used here.

  • OsirisEdit
    © 2021 Modbap Modular · portions © 2017 Andrew Belt · GPL-3.0

    The C++ desktop editor, a modified version of WaveEdit adapted to the Modbap Osiris hardware spec: Osiris terminology, the Convert / WavPak SD-card workflow, and clipboard additions.

  • OsirisEdit Web this app
    © 2026 Modbap Modular · portions © 2017 Andrew Belt · GPL-3.0

    The browser edition. The user interface was rebuilt on HTML, Canvas and Web Audio; the DSP core was ported from the C++ rather than rewritten, and is verified against it.

Third-party components

This edition bundles no third-party code. The upstream native dependencies were all replaced during the port: pffft by an in-tree real FFT that reproduces its ordered packing, Dear ImGui and SDL2 by browser APIs, libsamplerate and libsndfile by in-tree resampling and WAV code, and ZIP writing by an in-tree CRC-32 + STORE writer. jsdom is a test-only dependency and is never served to the browser.

The typefaces Barlow Condensed, Montserrat and Inter are loaded at runtime from the Google Fonts CDN. No font files are hosted or redistributed here.
